# NORMAS PARA LOS AGENTES DE IA



## Entorno de desarrollo



* Trabajaremos solo con Java 21
* IntelliJ
* Git (todos los comandos de git serán ejecutados por mí, tú no los hagas sin permiso)



## Toma de decisiones



* No tomes decisiones de diseño sin mi permiso. Si tuvieras alguna sugerencia o idea propia que consideres que se debería implementar me la explicas y me pedirás permiso para implementarla.



## Archivos



* No puedes crear ni modificar archivos sin mi permiso explícito. Si considerases, por ejemplo, que tuvieses que crear una clase nueva o modificar una ya existente sin que yo te lo haya mandado, entonces debes pedirme permiso para hacerlo.
* Puedes revisar el contenido de los archivos del repositorio en el que estemos trabajando si lo necesitas para adquirir contexto.
* No tienes permiso para borrar archivos por tu cuenta, debes preguntarme antes.



## Acerca del código



* No uses atajos. El código debe ser robusto y estar bien estructurado. No hagas chapuzas ni dejes de lado la calidad del programa en ningún momento.
* No uses soluciones demasiado complejas como para que un alumno de 2º de DAM no pueda comprenderlas.



## Control de excepciones y tests



* Todas las excepciones que puedan lanzarse durante la ejecución del programa deben ser tratadas correctamente como se especifica en STYLE.md
* Solo cuando yo te lo ordene, generarás baterías de pruebas en la carpeta tests del proyecto utilizando JUnit4. Todos los casos posibles deben ser tratados de forma correcta.



## Persistencia



* Debes usar exclusivamente JDBC.
* La persistencia en bases de datos se hará en MySQL.
* La persistencia en bases de datos debe respetar las otras formas de persistencia que se hayan implementado en el proyecto.
